The companion studio now follows the same scene setup as Character Motion Studio. Choose a character from the roster or enter a custom name, then start with one of four scene templates or write your own prompt.

Save a scene under a name to reuse it with any character. You can load, update, reset, and delete presets, and the browser keeps saved presets across reloads.

Browser checks verified that presets persist after reload and that the selected character and scene reach the generation request. The checks used simulated generation.
