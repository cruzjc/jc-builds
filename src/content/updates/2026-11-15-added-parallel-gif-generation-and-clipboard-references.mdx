The studio can start up to four variations from one set of choices. Each request keeps its own settings and references, so people can start another scene while earlier requests are still running. Finished GIFs can be previewed and downloaded individually, with filenames based on the submitted choices and timestamp. Reference images can be pasted from the clipboard.
