You can add a character reference image to the companion studio by choosing a file or pasting it from the clipboard. The editor accepts PNG, JPEG, and WebP and lets you preview or remove the image before generating. The attachment stays in the open page.

In Basic mode, the reference serves as the opening frame when you have not supplied a separate first frame. In Mixed references mode, it guides the character’s appearance.

Chromium checks exercised both file upload and clipboard paste. Simulated generation requests confirmed that the image arrived intact and was used according to the selected mode.
