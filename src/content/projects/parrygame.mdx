## Objective

Create an original first-person combat game in which continuous parries, weapon redirects, and contested firing lines reward recognition and positional decisions. A clean hit is usually lethal; the main opportunity to recover comes from regaining control of the exchange.

## How it works

Unity and C# provide the gameplay foundation, with Blender for original asset and animation production. A deterministic combat state graph governs each interception, both fighters' positions, and their available continuations. Shooting is a committed action that an opponent can disrupt before the firing frame. Readable threat cues, concise death explanations, and immediate retries support mastery.

## Current state

Production scope is confirmed for a finished Windows game intended for Steam, with score attack, training, challenges, and keyboard/mouse and controller support. Constrained duels use contextual stepping and redirects; simultaneous opponents are essential to the release. Cinematic realism will use original characters, assets, and choreography.

The release specification and production plan define internal validation gates before content expansion. Development uses free tools and resources, with no deadline set. Unity project import, combat-data generation, domain checks, and synthetic input transport checks have passed.

The first internal training room established aimed interception, contextual stepping, and earned firing across two opponents using one shared player state. That baseline passed automated simulation, synthetic device-path, and generated-scene checks, produced a Windows development build, and received separate offscreen scene and HUD inspection.

The current training iteration adds stop/go tutorial steps with unlimited reading and aiming time, spatial callouts, and original Blender rigs for the player and two opponents. These establish an initial paired-pose baseline. Accepted tutorial actions remain subject to the authoritative encounter rules. Automated combat, synthetic input, scene, and rig-import checks pass. A Windows development build and separate offscreen scene and HUD verification across the lesson steps and completion also passed.

Composited-window presentation, human combat playtesting, broader encounter feasibility, full paired choreography and final cinematic art, physical controller feel, and packaged Windows performance still need evidence. This internal scene is a production gate; finished-release acceptance remains ahead.
