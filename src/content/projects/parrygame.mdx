## Objective

Create an original first-person combat game in which continuous parries, weapon redirects, and contested firing lines reward recognition and positional decisions. A clean hit is usually lethal; the main opportunity to recover comes from regaining control of the exchange.

## How it works

The design brief proposes a deterministic combat state graph. Each interception changes both fighters' positions and available continuations. Shooting is a committed action that an opponent can disrupt before the firing frame. Readable threat cues, concise death explanations, and immediate retries support mastery.

## Current state

The project is in direction review. Unity is being considered, and the intended endpoint is a finished product. Target platforms, release content, visual style, and production resources still need decisions before implementation. No playable build is available.
